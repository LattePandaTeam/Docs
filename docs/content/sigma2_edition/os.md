# Operating Systems

This chapter provides a comprehensive guide on how to install an operating system that is compatible with LattePanda Sigma 2.

!!! note "Pre-installed Ubuntu OS"
    The 1TB SSD that ships with LattePanda Sigma 2 comes with **Ubuntu 26.04 LTS pre-installed**, along with GPU/NPU drivers and local AI models. If you do not need a different OS, you can use it directly out of the box — see [Local AI Quick Start](local_ai_getting_started.md).

## Compatible List

The following operating systems are officially tested on LattePanda Sigma 2:

| Operating System | Compatibility |
| ------- | :----: |
| Windows 11 Pro 25H2 | 🟢 |
| Ubuntu 24.04 LTS (kernel 7.0.0-28-generic) | 🟢 |
| Ubuntu 26.04 LTS (kernel 7.0.0-38-generic) | 🟢 |

!!! note "Mark Pattern"

    - 🟢 Green indicates that the OS can be installed normally, with basic ports and components such as USB, HDMI, Ethernet, PCIe, NPU, and iGPU working properly.
    - 🟡 Yellow indicates that additional installation or setup steps are required before the system to be fully installed and operational.
    - 🔴 Red indicates that the OS cannot be fully installed due to hardware or software compatibility issues.

If you discover that an operating system has undergone a significant update and needs to be retested, or if there are other operating systems that you would like us to test, you can either create a new issue in the repository of this document (https://github.com/LattePandaTeam/Docs/issues) or email us at [techsupport@lattepanda.com](mailto:techsupport@lattepanda.com).
